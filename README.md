# Punto Lácteo: gestión de ventas y stock

Repositorio del sistema de gestión de ventas y stock para el local Punto Lácteo, que vende lácteos, fiambres y quesos.

Por ahora contiene solo el material de aprendizaje previo al desarrollo: doce módulos (00 a 11) que recorren HTTP, FastAPI, el diseño de la base de datos, SQLAlchemy, la seguridad, TypeScript, React, Docker Compose y los patrones de diseño con un mini Punto Lácteo.
