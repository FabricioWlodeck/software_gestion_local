Material didácticoPunto Lácteo

Cómo se conecta un sistema web con FastAPI, MariaDB y React

Cada módulo explica una pieza del sistema con un mini Punto Lácteo reducido a tres entidades: productos, ventas y usuarios. Los módulos se estudian en orden, porque cada uno se apoya en el anterior.

Cómo usar este material

Todos los módulos tienen las mismas ocho secciones: problema, concepto, código mínimo, cómo se conecta, animación, errores comunes, ejercicios y documentación oficial. La animación se recorre con los botones o con las flechas del teclado. El código de cada módulo está en aprendizaje/etapas/ y se ejecuta siguiendo el README.md de su carpeta.
